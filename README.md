# NooRules Presale

Оценка, КП, прототипы и клиентские демо.

## Установка в Codex

```sh
codex plugin marketplace add git@github.com:EgorPaleev/noo-presale.git
codex plugin add noorules-presale@noorules-presale
```

Откройте проект и один раз вызовите `$noo-presale-setup`. Затем начните новый чат в этом проекте. Для обычной задачи посмотрите план и предлагаемый пайплайн в одном сообщении и напишите «запускай». Точечный запрос с понятным результатом можно выполнить сразу. Для явного входа используйте `$noo-presale-task`.

## Установка в Claude Code

```sh
claude plugin marketplace add git@github.com:EgorPaleev/noo-presale.git
claude plugin install noorules-presale@noorules-presale --scope project
```

Откройте Claude Code в целевом проекте и вызовите `/noorules-presale:noo-presale-setup`. Затем начните новую сессию.

Навыки и материалы лежат в `plugins/noorules-presale/` и готовы к установке из этого репозитория.

При первом использовании плагин напоминает обновить marketplace и пакет. `setup` создаёт только `.noorules/presale/rules.md` и блок входа для этого плагина. Повторный `setup` сохраняет существующие проектные файлы.

## Пресейл

Рабочие команды действуют после подключения текущего проекта через setup. Начать можно с сообщения, заметок, ссылки, примеров или готового документа. Если данных для части результата не хватает, плагин выполнит доступную работу и укажет, что нужно уточнить.

- `$noo-presale-flow запусти presale-full по этим вводным` сначала показывает план, вопросы, проверки и исполнителей. После «запускай» формирует комплект с исследованием клиента и кликабельным прототипом для десктопа и телефона. Ход этапов виден в чате.
- `$noo-presale-stage собери план пресейла по этим вводным` возвращает только план исполнения.
- `$noo-presale-stage составь смету по приложенному плану работ` выполняет один этап. Аналогично можно вызвать разбор, план работ, КП, демо или сверку.
- `$noo-presale-stage собери демо по этому кейсу` готовит и проверяет десктопную и мобильную версии за один запуск.
- `$noo-presale-stage исследуй клиента по этим материалам` запускает отдельную ветку исследования.

По окончании временные материалы удаляются. Выдача остаётся в `presales/<id>/` или в папке пользователя. Для сборки XLSX нужен Python с установленным `openpyxl`.

Все режимы используют [единый регламент NooSoft](plugins/noorules-presale/assets/knowledge/base/presale/workflows/presale-playbook.md).
