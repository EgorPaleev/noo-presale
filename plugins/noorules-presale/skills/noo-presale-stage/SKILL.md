# Этап NooRules Presale

Сначала [проверь подключение текущего проекта](../noo-presale-task/references/project-context.md#подключение-проекта). Выполняй этот навык NooRules Presale в подключённом проекте.

Открой [единый регламент](../../assets/knowledge/base/presale/workflows/presale-playbook.md) на разделе выбранного этапа. Возьми имена входов и выхода из [контрактов](../../assets/knowledge/flows.json). Полный автоматический прогон передавай в [noo-presale-flow](../noo-presale-flow/SKILL.md) с именем `presale-full`.

- При явном вызове или передаче из пайплайна выполни выбранный этап. Понимай короткие команды «разбор», «план работ», «смета», «КП», «демо», «сверка», «исследование клиента». Если просят «план пресейла», составь план исполнения по [правилам подбора](../noo-presale-flow/references/composition.md).
- Для сверки отдельного результата используй доступные артефакты и критерии выбранного этапа. Для проверки всего комплекта нужны его входы по контракту.
- Для отдельного вызова демо принимай готовый функциональный кейс, если в нём есть сценарии и границы показа. Для кликабельного прототипа открой [noo-presale-prototype](../noo-presale-prototype/SKILL.md) и передай туда кейс и требования к платформам.
- Принимай материалы в любом доступном виде, включая сообщение, заметки, ссылку, примеры и готовые файлы команды. Сопоставляй их по содержанию с ролью входа. Извлеки достаточный минимум из исходников, если готового артефакта нет. Выполни доступную часть, пометь допущения и черновики. Запроси конкретные данные только для результата, который без них нельзя получить.
- Сохрани результат по договорённому пути и приложи фактически выполненные проверки. Для комплекта с несколькими файлами укажи их в основном артефакте этапа и в зависимостях результата запуска. При самостоятельном вызове верни файлы, статус готовности и существенные открытые решения.
