# Подключение NooRules Presale

Если пользователь просит обновить плагин, используй [порядок обновления](../noo-presale-task/references/version.md). При обычном первом вызове в сессии один раз напомни об обновлении перед использованием и продолжи настройку.

Найди корень текущего проекта и корневую точку входа текущего клиента. Прочитай её для выбора места подключения. Выполни [минимальное подключение](references/project-layout.md). Изменения ограничены правилами этого плагина и его блоком входа. Если по правилам проекта нужны другие файлы или действия, укажи их в результате проверки.
