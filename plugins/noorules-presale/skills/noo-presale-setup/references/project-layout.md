# Подключение проекта

`setup` владеет только `.noorules/presale/rules.md` и своим блоком входа в корневых инструкциях. Создай правила из шаблона при первом подключении. При повторном запуске сохраняй существующий файл правил и любой уже действующий блок этого плагина.

Из корня целевого проекта вызови `python3 <путь-к-noo-presale-setup>/scripts/connect_project.py --project . --entry AGENTS.md` для Codex или укажи `--entry CLAUDE.md` для Claude Code. Если корневой файл клиента явно подключает общий корневой файл, передай имя этого общего файла. Если доступна только работа без Python, примени те же границы вручную. Плагин добавляет в выбранный файл отдельный блок `noorules:presale:task-entry` с вызовом `noo-presale-task`. Действующий старый блок `noorules:task-entry` с этим навыком подходит.

Существующие инструкции, блоки другого направления, старые файлы `.noorules/`, Git-настройки, команды проверок, зависимости, ADR, README, исходники и документы проекта доступны как источники. Для их изменения нужно отдельное поручение. При `setup` их не редактируй. Уточнения по работе NooRules Presale добавляй в его файл правил по прямому поручению пользователя.

После запуска сверь список изменённых путей с этими границами. При наличии локальных правок сравни только внесённые изменения. Кратко сообщи, какие файлы созданы и где находятся правила. Если изменения не потребовались, сообщи об этом. После нового подключения предложи открыть новую сессию.
