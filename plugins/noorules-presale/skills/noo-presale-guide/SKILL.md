# Выбор навыка NooRules

Сначала [проверь подключение текущего проекта](../noo-presale-task/references/project-context.md#подключение-проекта). Выполняй этот навык NooRules Presale в подключённом проекте.

Если пользователь просит посоветовать пайплайн, [подбери цепочку по результату и имеющимся входам](../noo-presale-flow/references/composition.md). Покажи подходящий сценарий или короткую последовательность этапов, назови материалы, которые можно переиспользовать, и дай пример вызова. Для выполнения предложи `noo-presale-task`, а для названного сценария — `noo-presale-flow`. Заверши ответ на рекомендации.

По результату, который нужен человеку, и уже доступным материалам предложи кратчайший маршрут. Для вопроса о направлении используй [карту направлений](../../assets/knowledge/directions.md). Для узкой задачи открой [карту типов](../../assets/knowledge/task-index.md). Запрос «какой навык выбрать» завершается рекомендацией.

## Навыки по результату

- Старт в репозитории — `noo-presale-setup`.
- Неясное требование или термин — `noo-presale-clarify`.
- Кликабельное демо — `noo-presale-prototype`.
- Разбор пресейл-вводных, план, смета, КП, исследование клиента или сверка — `noo-presale-stage`.
- Комплект от вводных до сверки — `noo-presale-flow` с именем `presale-full`.
- Выбор модели для задачи или нескольких шагов — `noo-presale-model`.
- Несколько этапов с передачей файлов и возможностью продолжить — `noo-presale-flow`.
- Для рекомендации отдельных инструкций используй `noo-presale-rules`.
