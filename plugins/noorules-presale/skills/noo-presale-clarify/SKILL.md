# Уточнение задачи

Сначала [проверь подключение текущего проекта](../noo-presale-task/references/project-context.md#подключение-проекта). Выполняй этот навык NooRules Presale в подключённом проекте.

Прочитай текущие требования, глоссарий и ADR затронутой области. Определи пользователя, ожидаемое изменение и проверяемый результат. Проверь по коду вопросы, которые можно решить исследованием репозитория. В разговор вынеси развилки, где выбор меняет объём, контракт или критерии.

Используй [раздел разбора в регламенте пресейла](../../assets/knowledge/base/presale/workflows/presale-playbook.md). При наличии проектного словаря внеси согласованный термин по правилам проекта. Для открытого вопроса укажи влияние на объём или приёмку.

Для этапа `discovery` итог — бриф с границами и вопросами. Для `analysis` итог — функциональный кейс с основным сценарием, альтернативами и критериями. Если вызов сделан из пайплайна, сохрани итог в предложенный файл артефакта.
