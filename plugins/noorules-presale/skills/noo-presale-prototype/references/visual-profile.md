# Визуальный профиль пресейла

Используй для нового прототипа без заданной дизайн-системы. Перенеси семантические роли в тему приложения, CSS-переменные или стили макета.

## Типографика

| Роль | Шрифт | Применение |
| --- | --- | --- |
| Заголовки | Manrope 600–700 | H1 примерно 28–40 px, H2 24–32 px, заголовки карточек 18–22 px. Меньший край диапазона подходит узким экранам. |
| Кнопки и сегменты | Manrope 600 | Подпись обычной кнопки 15 px в естественном регистре. |
| Числа | Manrope 600–700 | Таймеры, проценты, счётчики и коды. В динамических значениях используй табличные цифры, чтобы ширина не менялась. |
| Основной текст и подписи | Roboto 400/500 | Основной текст 16 px с межстрочным интервалом 1,55, второстепенный 14 px с интервалом 1,5, подписи 13 px. Roboto 700 подключай для жирного выделения в тексте. |

Подключай латиницу и кириллицу для обеих гарнитур. Для веба используй `font-display: swap`, `font-synthesis: none` и запасной стек `"Helvetica Neue", Arial, sans-serif`. В нативном прототипе сопоставь роли с типографикой приложения и проверь масштабирование системным размером текста. В макете и работающем прототипе проверь одну и ту же длинную русскую подпись.

## Иконки

- Используй Phosphor для продуктовых иконок. В React переиспользуй `@phosphor-icons/react`. Для других форматов используй доступные ассеты Phosphor того же веса или существующие компоненты проекта.
- Базовый вес `regular`. `fill` обозначает выбранный или сохранённый элемент, например закладку. `bold` подходит небольшим стрелкам внутри кнопок. Для рядов и полей начни с 16–20 px, для навигации и крупных действий — с 20–24 px. В одинаковых ролях сохраняй размер и вес.
- Называй действие доступной подписью на самой кнопке. Если значок дублирует видимую подпись, скрой его от средств чтения с экрана. Оставь области нажатия достаточно места на телефоне. Для текущего раздела используй подпись и программный признак выбранного состояния.
- Для ориентира: поиск — `MagnifyingGlass`, назад — `ArrowLeft`, закрыть — `X`, избранное — `BookmarkSimple`, место — `MapPin`. Логотипы и фирменные иконки загружай из ассетов конкретного продукта.

## Палитра

| Токен | Светлая | Тёмная | Роль |
| --- | --- | --- | --- |
| `surfaceBase` | `#f5f7fa` | `#0e1114` | Фон приложения |
| `surfaceRaised` | `#fdfdff` | `#171a1e` | Карточки, поля, модалки |
| `surfaceSunken` | `#eceff5` | `#131519` | Подложки, скелетоны |
| `textPrimary` | `#1b2129` | `#f2f3f6` | Заголовки и основной текст |
| `textSecondary` | `#5a616b` | `#a6abb3` | Описания и подписи |
| `textTertiary` | `#696f78` | `#8e939a` | Метаданные и плейсхолдеры |
| `line` / `lineHover` | `#e0e3e8` / `#b5bbc4` | `#2d3136` / `#51565d` | Разделители, контуры и наведение |
| `accent` / `accentHover` | `#3063c6` / `#2352ad` | `#79a6e9` / `#97bdf4` | Ссылки, фокус и акцентные элементы |
| `accentSoft` | `#e3edff` | `#1a2b49` | Акцентная подложка |
| `actionPrimary` / `actionPrimaryText` | `#3063c6` / `#fdfdff` | `#f2f3f6` / `#0e1114` | Фон и текст основной кнопки |
| `actionPrimaryHover` | `#2352ad` | `#dbdee3` | Основная кнопка при наведении |
| `live` | `#2a9754` | `#4dbf74` | Успех и активное событие |
| `warning` | `#e09a46` | `#ecb166` | Предупреждение |
| `error` | `#d03736` | `#e66e6a` | Ошибка и опасное действие |
| `headingFrom` → `headingTo` | `#1b2129` → `#234993` | `#f2f3f6` → `#a2b2cb` | Градиент крупного заголовка |

- Храни значения в теме и обращайся к ролям в компонентах. Используй холодную нейтральную шкалу: фон, приподнятая поверхность и подложка. На тёмных поверхностях разделяй слои преимущественно линией, на светлых допустима мягкая графитовая тень.
- Для главной кнопки используй пару `actionPrimary` и `actionPrimaryText`. Держи `accent` отдельным токеном для ссылок, активных элементов и фокуса. При пользовательском акценте ограничивай переопределение нужным разделом и выбирай цвет текста по контрасту.
- Для ошибок, предупреждений и успеха сочетай цвет с подписью или иконкой. Проверяй контраст на той поверхности, где элемент реально отрисован. Сами по себе токены статуса не гарантируют читаемость мелкого текста. Например, предупреждение можно показать оранжевой иконкой рядом с текстом основного цвета.
- Поддерживай одинаковые семантические роли в обеих темах. Если сценарий включает смену темы, проверь фокус, CTA, выбранное состояние и ошибку до и после переключения. Для браузерного прототипа с переключателем используй системное предпочтение при первом открытии и сохраняй явный выбор пользователя.

## Компоненты и проверка на разных размерах

Поля 14 px, карточки 20 px, панели 24 px, листы и модалки 28 px. Для кнопок, фильтров-чипов и сегментов используй форму пилюли. Основная кнопка начинается от 44 px по высоте в обычном размере. На телефоне проверяй длинные подписи и область касания, на десктопе — наведение и видимый фокус. На общей странице сравни заголовок, поле, карточку и основной CTA в обеих темах. Если нужен градиентный заголовок, оставь его крупным и проверь читаемость по всей ширине.
