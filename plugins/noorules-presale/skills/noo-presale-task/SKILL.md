# Работа с задачей

Сначала [проверь подключение текущего проекта](references/project-context.md#подключение-проекта). Выполняй этот навык NooRules Presale в подключённом проекте.

Если координатор передал тебе отдельный этап уже согласованного пайплайна, сразу выполни его по контракту и [правилам для субагента](../noo-presale-flow/references/delegation.md). При отсутствии отдельного навыка-исполнителя используй материалы маршрута.

## Вход

- Явный запрос «обнови плагин» выполни по [порядку обновления](references/version.md).
- При явном вызове другого навыка используй его инструкции. На справочный вопрос отвечай прямо.
- Для пресейла используй [единый регламент](../../assets/knowledge/base/presale/workflows/presale-playbook.md). Новый запрос «собери пресейл полностью» веди через план и вопросы по `presale-full`. Полный комплект включает кликабельное демо для десктопа и телефона, если пользователь не ограничил выдачу. Отдельный разбор, план, смету, КП, демо, сверку или исследование клиента передавай в [noo-presale-stage](../noo-presale-stage/SKILL.md).
- Если запрос явно ограничен самостоятельным действием с понятным результатом, выбери [навык по результату](../noo-presale-guide/SKILL.md#навыки-по-результату), открой его файл `../<имя-навыка>/SKILL.md` и сразу выполни инструкции. Если запрос соответствует одному специализированному маршруту из базы направления, используй его контракт и материалы. Например, «подбери модель для ревью» означает рекомендацию по модели. Определи границу по смыслу. Если часть вводных отсутствует, используй доступные материалы и выполни возможную часть. Укажи, чего не хватает и как это влияет на результат. Верни результат навыка в запрошенном формате. Если в этом чате ждёт согласования другой план, сохрани его на текущем шаге.
- Если пользователь отвечает на ожидающее согласование, примени [правила согласования](../noo-presale-flow/references/approval.md). Для запроса с несколькими связанными действиями или открытым объёмом предложи план работы. Обычный запрос на изменение кода проходит через план, даже если ожидаемый результат один.

## Работа по плану

Изучи вводные и сверь проектные материалы. Подбери [пайплайн](../noo-presale-flow/references/composition.md), а для каждого этапа выбери [модель и исполнителя](../noo-presale-flow/references/delegation.md). Покажи план, пайплайн и вопросы по [правилам согласования](../noo-presale-flow/references/approval.md). После команды запуска передай принятый план, исходники и проверки в [noo-presale-flow](../noo-presale-flow/SKILL.md). Если отдельный механизм вызова недоступен, прочитай файл и начни исполнение в этом же ходе.
