# Обновление NooRules Presale

Перед первым использованием в сессии один раз скажи пользователю: «Рекомендую обновить NooRules Presale один раз перед работой. Сначала обнови marketplace, затем сам плагин. Могу сделать это по команде „обнови плагин“». Дай шаги для текущего клиента. Скажи это и при недоступной сети или при совпадающих версиях. Если обновление уже завершено в этой сессии, напоминание не нужно. Сразу продолжай запрошенную задачу.

По команде «обнови плагин» выполни обе операции последовательно для установленного клиента. Покажи, что получилось, и предложи открыть новую сессию для проверки активной версии. Для источника, закреплённого на версии или локальной копии, сохрани выбранный способ установки.

- **Codex CLI.** Сначала `codex plugin marketplace upgrade noorules-presale`. После успеха выполни `codex plugin add noorules-presale@noorules-presale`.
- **Claude Code.** Сначала `claude plugin marketplace update noorules-presale`. После успеха выполни `claude plugin update noorules-presale@noorules-presale --scope project` для проектной установки. Для других установок используй их действующий scope.
- **Приложение.** Если команды недоступны, укажи шаги через список плагинов или обновление установленного источника. Если первый шаг завершился ошибкой, укажи это и сохрани текущую установку.
