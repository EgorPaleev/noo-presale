# Контекст NooRules Presale

## Подключение проекта

Проверяй подключение к текущему проекту перед любым рабочим запуском, включая явный вызов, продолжение по ID и работу переданного этапа.

- Найди корень текущего проекта. Для Git используй корень текущей рабочей копии. Для папки без Git используй открытый корень проекта. Прочитай корневой файл клиента (`AGENTS.md` для Codex или `CLAUDE.md` для Claude Code). Общий файл учитывай, если корневые инструкции этого клиента его подключают.
- В этих инструкциях должен быть действующий блок `<!-- noorules:presale:task-entry -->` с точкой входа `noo-presale-task`. Подходит также старый `<!-- noorules:task-entry -->`, если он явно подключает этот навык. Упоминание навыка в примере, глобальных инструкциях, соседнем проекте или блок другого направления не подключает текущий проект.
- Если подходящего блока нет или его нельзя проверить, не запускай рабочий маршрут NooRules Presale. Обычный запрос обрабатывай по правилам текущего проекта. При явном вызове коротко укажи, что проект ещё не подключён и для подключения можно явно вызвать `noo-presale-setup`. Самостоятельно настройку не запускай.
- Явный вызов `noo-presale-setup` служит для подключения проекта. Установка пакета делает его команды доступными в клиенте. Активировать рабочий процесс для проекта позволяет настроенный блок.

При первом рабочем запуске после проверки проекта [один раз напомни об обновлении](version.md) и продолжи задачу. Пропусти напоминание при явном запросе на обновление или если в этой сессии уже был совет от setup, напоминание или обновление. На этапах и в субагентах пропускай напоминание.

Прочитай правила этого плагина в `.noorules/presale/rules.md`, если файл есть.
