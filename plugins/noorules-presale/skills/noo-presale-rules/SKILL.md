# Подбор правил

Сначала [проверь подключение текущего проекта](../noo-presale-task/references/project-context.md#подключение-проекта). Выполняй этот навык NooRules Presale в подключённом проекте.

1. В базе `../../assets/knowledge/` относительно этого навыка открывай `routes/<тип>.json` для известного маршрута. При неизвестном типе используй [карту задач](../../assets/knowledge/task-index.md). Для точного ID открой только его запись в `lookup/<раздел>/<тип>.json`. При промахе проверь ID в [алиасах](../../assets/knowledge/aliases.json). Полный `index.json` нужен для точечного поиска метаданных, отсутствующих в остальных указателях.
2. Прочитай действующие инструкции проекта и подходящие записи `.noorules/local/tasks.json` для типа задачи и `*`, если файл существует. Если локальный материал ограничен условиями профиля или областью проекта, сверь их с текущими файлами.
3. При планировании используй контракт маршрута и метаданные. Открывай содержание, если оно меняет объём, результат или способ проверки. При выполнении прочитай подходящие материалы `default`. Для `on-demand` проверь `when`, если задано, и открой материал, когда он нужен для конкретного решения или проверки. Используй один экземпляр каждого разрешённого пути и повторно обращайся к нему только при изменении файла или необходимости сверить деталь.
4. Для `projectPath` сначала используй существующий файл проекта, затем при необходимости снимок из `base/`. Сверяй `project-snapshot` с текущими файлами проекта, а `tool-snapshot` с версией инструмента. Документ `historical` используй для истории или сравнения.
5. В режиме подбора верни подходящие ID с краткой причиной. При выполнении свяжи каждый применённый материал с решением, изменением или проверкой. Фиксируй как применённые только материалы, которые повлияли на работу.
