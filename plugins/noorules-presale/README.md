# NooRules Presale

Пресейл, оценка, прототипы и клиентские демо.

Установите пакет `noorules-presale@noorules-presale` и откройте рабочую папку проекта. Для автоматического входа подключите проект через `$noo-presale-setup`. Для явного вызова используйте `$noo-presale-task`.

Для обычной задачи согласуйте подзадачи, посмотрите предложенный способ исполнения и дайте команду запуска. Точечный запрос с понятным результатом можно выполнить в одном ответе.
